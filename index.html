Morphe Android TV Patches

Guide d'installation et état des patchs pour Android TV

📥 Comment installer

Tous les patchs suivent la même procédure, avec Morphe Manager :

  1. Télécharger le bon fichier .apkm Android TV depuis APKMirror (liens directs dans le README du dépôt).
  2. Dans Morphe Manager, vérifier que « Optimiser pour l'architecture de l'appareil » est désactivé.
  3. Ouvrir Morphe Manager et sélectionner le fichier .apkm.
  4. Appliquer le patch.

⚠️ Prendre la version Android TV, pas celle du téléphone ni de Fire TV

Plusieurs applications existent en version téléphone et/ou Fire TV sous le même nom de paquet : le patch serait alors incorrect ou sans effet. Respecter la version exacte indiquée, télécharger le .apkm (App Bundle) et non un .apk d'une seule architecture. Si plusieurs bundles sont proposés, choisir celui dont la colonne d'architecture inclut armeabi-v7a.

🛑 Désactiver « Optimiser pour l'architecture de l'appareil » avant de patcher

C'est un réglage du mode Expert (désactivé par défaut). Activé, le Manager ne conserve que l'architecture du processeur de l'appareil qui effectue le patch. Patcher sur un téléphone (arm64) puis installer sur un boîtier TV peut faire perdre les bibliothèques armeabi-v7a dont dépendent de nombreuses applications TV (Prime Video, Netflix). Symptômes : installation impossible, fermeture immédiate au lancement, ou patch sans effet. Dans ce cas, désactiver l'option et patcher de nouveau. (Patcher directement sur la TV n'est pas concerné.)

▶️ Prime Video
Publicités films et séries (bandeau natif) · ⚠️ rester sur 6.23.23
Version : 6.23.23+v15.5.0.70-armv7a

Bandeau publicitaire natif intégré à l'application, pour les films et les séries. Pas de DNS nécessaire.

⚠️ Rester sur 6.23.23 (moteur v15.5.x). Ne PAS passer à 6.24.x (moteur v16) : Amazon a déplacé la gestion des publicités dans le moteur natif de l'application, et les publicités reviennent. Laisser « Désactiver les mises à jour automatiques » activé. Si vous êtes déjà en 6.24.x, désinstaller puis réinstaller 6.23.23.
  1. Ouvrir Prime Video (Android TV) 6.23.23+v15.5.0.70-armv7a sur APKMirror (armeabi-v7a uniquement : « Optimiser pour l'architecture » doit donc être désactivé).
  2. Télécharger le fichier .apkm.
  3. Le sélectionner dans Morphe Manager.
  4. Appliquer le patch.
🟢 Fonctionne, sans filtre DNS. Les publicités sont retirées dans l'application par un hook natif : films et séries se lisent sans publicité, sans liste de blocage DNS, proxy ni root. Les pré-rolls et mi-rolls des films et des séries sont supprimés sur l'appareil avant lecture.
La suppression des publicités des séries est récente (v1.16.0) et en test élargi. Cas limite connu : une avance rapide très agressive suivie d'une reprise peut décaler la position de lecture ; cela se corrige tout seul en lecture complète. Les très longues coupures mi-roll peuvent rarement figer brièvement l'écran (roue / « Something went wrong ») : appuyer sur Retour, puis sur Reprendre. La version v1.37.4 renforce le bandeau pour les régions très chargées en publicité (Inde/UE).
🍿 Netflix
Publicités pré/mi-roll + de pause · s'installe comme un clone
Version : 13.0.1 build 25028

Bandeau publicitaire natif (pré-roll, mi-roll, publicité de l'écran de pause). Pas de DNS nécessaire. S'installe comme un clone côte à côte : garder Netflix d'origine installé.

🟢 Fonctionne, sans filtre DNS. Les pré-rolls, mi-rolls et la publicité plein écran de la pause sont retirés dans l'application, par un script exécuté par l'application elle-même (ni PC, ni root).
ℹ️ La logique publicitaire de Netflix est du JavaScript téléchargé, pas intégré à l'APK : Netflix peut modifier la diffusion côté serveur à tout moment, et une publicité peut parfois réapparaître jusqu'à la mise à jour du patch. Si vous voyez une publicité, vérifiez d'abord que vous avez le dernier patch ; si elle persiste, ouvrez une « issue » sur le dépôt.
🔐 Deux applications, volontairement : garder les DEUX installées. Sur une TV, Netflix est une application système préinstallée qui ne peut pas être remplacée ni désinstallée sans root. Le patch s'installe donc comme un clone séparé (com.netflix.ninja.clone). Netflix d'origine doit rester installé et activé (il suffit de ne jamais l'ouvrir ; les mises à jour automatiques sont sans danger). Se connecter dans le clone et l'utiliser. Ne pas désactiver ni désinstaller Netflix d'origine, sinon le clone ne démarre pas.
  1. Ouvrir Netflix (Android TV) 13.0.1 build 25028 sur APKMirror (éditeur Netflix, Inc., paquet com.netflix.ninja).
  2. Télécharger le bundle .apkm : c'est la seule variante, armeabi-v7a uniquement, donc « Optimiser pour l'architecture » doit être désactivé. Morphe Manager l'affichera comme « Recommended ». Ne pas prendre une version 13.1.x : le patch vise 13.0.1 build 25028.
  3. Le sélectionner dans Morphe Manager.
  4. Appliquer le patch en laissant Clone Netflix et Remove Netflix ads activés (par défaut). En option : Minimize Network Fingerprint (confidentialité : masque IP/MAC/SSID locaux et identifiant publicitaire).
  5. Installer le résultat sans désinstaller Netflix d'origine, puis ouvrir la nouvelle application Netflix clone et s'y connecter.
⚠️ Ce n'est pas un contournement d'abonnement. Un compte Netflix valide et payant est nécessaire, avec une connexion normale. Le patch retire seulement les publicités et réduit la télémétrie dans une application que vous avez déjà le droit d'utiliser.

🦚 Peacock
Publicités VOD
Versions : 7.10.102 · 7.8.100

Pas de DNS nécessaire.

  1. Ouvrir directement Peacock TV (Android TV) 7.8.100 sur APKMirror (utiliser ce lien plutôt que la recherche, qui peut mener à un build au nom voisin). Les versions 7.10.102, 7.5.102 et 7.6.100 sont aussi prises en charge.
    Cette version propose trois bundles : choisir arm64-v8a + armeabi-v7a (Android 6.0+). Le bundle armeabi-v7a seul exige Android 12+, et celui en arm64-v8a seul ne fonctionnera pas sur les boîtiers TV 32 bits.
  2. Télécharger le fichier .apkm.
  3. Le sélectionner dans Morphe Manager.
  4. Appliquer le patch.
⚠️ Fire TV et appareils où Peacock est préinstallé (application système) : activer le patch « Clone Peacock » avant d'appliquer. Sur de nombreuses clés Fire TV et certains boîtiers Android TV, Peacock est une application système impossible à désinstaller ; installer le build patché par-dessus échoue avec une erreur de signature ou CONFLICTING_PROVIDER. Le patch Clone Peacock (optionnel, désactivé par défaut) installe l'application patchée à côté, sous son propre paquet : une seconde icône Peacock apparaît, avec sa propre connexion. Le laisser désactivé seulement si vous avez pu désinstaller complètement Peacock d'origine (une installation normale est plus propre). Le patch Disable auto-updates est activé par défaut : il empêche le Play Store de remplacer silencieusement le build patché.

📡 Pluto TV
Publicités VOD · coupures du direct masquées (optionnel)
Version : 5.66.0-leanback

Coupures publicitaires VOD supprimées (vidéo, marqueurs, balises de suivi). Les coupures du direct peuvent être masquées (écran noir + sourdine) avec un patch optionnel.

🟢 Fonctionne. Pluto est un service gratuit, financé à 100 % par la publicité (FAST), qui utilise l'insertion publicitaire côté serveur (SSAI) : les publicités sont intégrées au même flux que le contenu, donc aucun domaine à bloquer et aucune offre sans publicité à débloquer. Le patch vide la chronologie des coupures côté client, ce qui supprime entièrement les coupures VOD : vidéo publicitaire, marqueurs, superpositions et balises de suivi. Les publicités de la TV en direct occupent du vrai temps d'antenne et ne peuvent pas être retirées, mais le patch distinct Mask live ad breaks les masque. Les filtres DNS ne servent à rien ici.
  1. Ouvrir Pluto TV (Android TV) 5.66.0-leanback sur APKMirror (version 5.66.0-leanback ; la liste affiche aussi des versions 17.x plus récentes, mais le patch vise 5.66.0-leanback).
  2. ⚠️ Utiliser cette liste Android TV et choisir un build -leanback : pas la version téléphone ni Fire TV.
  3. Télécharger le fichier .apkm.
  4. Le sélectionner dans Morphe Manager.
  5. Appliquer le patch.
📺 Mask live ad breaks (écran noir + sourdine). Les publicités du direct occupent du vrai temps d'antenne et ne peuvent pas être supprimées comme en VOD : ce patch optionnel masque donc la coupure. Pendant une coupure en direct, il couvre le lecteur d'un écran noir et coupe le son, puis rétablit les deux dès le retour de l'émission. Il lit le signal d'état publicitaire de Pluto, fonctionne avec le patch principal Skip ads et est « opt-out » (le laisser désactivé pour voir normalement les publicités du direct).

Réglages à l'exécution, par fichiers repères dans le dossier de fichiers externes de l'application (Android/data/tv.pluto.android/files/) : créer slate_off pour le désactiver sur l'appareil sans re-patcher, ou pluto_slate_mode contenant black (écran seul) ou mute (son seul) au lieu des deux par défaut.

💜 Twitch
Bandeau pub + publicités du direct masquées · version TV uniquement
Version : 13.0.0.2

Build Android TV « Starshot » uniquement : installer exactement 13.0.0.2 (l'application du téléphone n'est pas prise en charge). Supprime la superposition / le compte à rebours publicitaire (« Ad · 1 of 3 ») et efface la vidéo publicitaire insérée (SSAI) dans les directs. Un bref écran noir peut subsister pendant une coupure ; un VPN réglé sur l'Albanie donne un direct totalement sans publicité.

🟢 Fonctionne : Android TV, build « Starshot » uniquement (13.0.0.2). Les publicités du direct Twitch sont insérées côté serveur (SSAI) dans le même flux que le contenu, et l'application TV exécute le lecteur web de Twitch dans une WebView. Le patch intercepte la playlist HLS du direct et (a) retire les balises publicitaires côté client qui commandent la superposition « Ad · 1 of 3 », et (b) vide la vidéo publicitaire insérée. Les vraies coupures ne se jouent plus comme des publicités. Comme la publicité occupe du temps réel du direct, un bref écran noir peut subsister pendant la coupure : la vidéo publicitaire a disparu, mais cette tranche de temps doit s'écouler. Les filtres DNS ne servent à rien ici.
💡 Zéro publicité et pas d'écran noir ? Régler un VPN sur l'Albanie : Twitch y sert des playlists réellement sans publicité. Vérifié avec NordVPN → Albanie ; associé au patch, vous êtes entièrement couvert.
  1. Ouvrir Twitch: Live Streaming (Android TV) 13.0.0.2 sur APKMirror (version 13.0.0.2).
  2. ⚠️ Utiliser cette liste Android TV et le build « Starshot » exact 13.0.0.2 : pas la version téléphone ni Fire TV (le patch cible précisément ce build TV). La version propose deux bundles, les deux fonctionnent ; arm64-v8a + armeabi-v7a est le choix sûr.
  3. Télécharger le fichier .apkm.
  4. Le sélectionner dans Morphe Manager.
  5. Appliquer le patch.
🏈 ESPN
Coupures du direct masquées (écran + sourdine) · publicités VOD
Version : 6.11.1

Android TV uniquement. Les coupures publicitaires du direct sont masquées par un écran plein écran avec coupure du son (la publicité SSAI « passthrough » ne peut pas être retirée, seulement recouverte) ; les publicités VOD / programmées sont supprimées. Pas de DNS nécessaire.

🟢 Fonctionne : Android TV uniquement (6.11.1). Les coupures du direct ESPN sont du SSAI natif « passthrough » : la publicité est intégrée au même flux que le match, donc elle ne peut pas être retirée, seulement masquée. Le patch détecte chaque coupure à partir des marqueurs publicitaires du flux et recouvre le lecteur d'un écran plein écran tout en coupant le son, puis le retire proprement à la reprise du direct. Les publicités VOD / programmées sont supprimées séparément. Les filtres DNS n'aident pas ici.
  1. Ouvrir directement ESPN (Android TV) 6.11.1 sur APKMirror (version 6.11.1) : utiliser ce lien plutôt que la recherche, pour éviter la version téléphone ou une autre version.
  2. ⚠️ Utiliser cette liste Android TV et le build exact 6.11.1 (paquet com.espn.score_center).
  3. Télécharger le fichier .apkm.
  4. Le sélectionner dans Morphe Manager.
  5. Choisir les options de patch (ci-dessous) puis appliquer.

📺 RTÉ Player
Publicités VOD · 🇮🇪 accès restreint à l'Irlande
Version : 3.160.3

Android TV, VOD uniquement. Les publicités côté client (Google IMA), pré-roll et mi-roll, sont retirées de façon transparente : ni publicité, ni pause. Les chaînes en direct gardent leurs publicités (insérées côté serveur). Accès restreint à l'Irlande : utiliser un VPN ; un compte RTÉ valide est nécessaire.

  1. Ouvrir RTÉ Player (Android TV) 3.160.3 sur APKMirror (version 3.160.3).
  2. Télécharger le fichier .apkm.
  3. Le sélectionner dans Morphe Manager.
  4. Appliquer le patch.
🟢 Fonctionne : Android TV, VOD uniquement. Les publicités pré-roll et mi-roll côté client (Google IMA) sont retirées dans l'application : le contenu se lit directement là où une coupure aurait lieu, sans publicité ni pause. Aucun filtre DNS nécessaire.
⚠️ Restreint à l'Irlande. RTÉ Player ne diffuse que depuis une adresse IP irlandaise : il faut donc un VPN réglé sur l'Irlande (et un compte RTÉ valide : le patch ne retire que les publicités, ce n'est pas un contournement d'accès).
ℹ️ Les chaînes en direct affichent toujours des publicités. Le direct est inséré côté serveur (DAI) dans la vidéo elle-même, ce qui ne peut pas être retiré côté client sans casser le flux : seul le contenu à la demande (VOD) est couvert. Un marqueur de coupure purement visuel peut encore apparaître sur la barre de progression, mais il ne met plus la lecture en pause.
